# 🧹 Depurador Automático de Datos Excel/CSV en Python  
### Proyecto profesional orientado a calidad de datos, automatización y análisis

Este proyecto demuestra mi capacidad para **diseñar, desarrollar y documentar soluciones reales de limpieza y validación de datos** utilizando Python.  
La herramienta automatiza procesos clave de calidad de datos, genera reportes profesionales y produce archivos listos para análisis o carga en sistemas.

---

## 🎯 Propósito del proyecto

Los equipos de datos suelen recibir archivos Excel/CSV con errores que afectan reportes, dashboards y modelos.  
Este proyecto resuelve ese problema mediante:

- **Automatización completa del proceso de depuración**  
- **Detección inteligente de errores**  
- **Generación de reportes claros para auditoría**  
- **Visualización del histórico de errores**  
- **Producción de un archivo limpio y documentado**

Es un ejemplo directo de cómo aplico Python para mejorar la calidad de datos y optimizar flujos de trabajo.

---

## 🚀 Funcionalidades principales

### ✔ Limpieza automática
- Normalización de texto y formatos  
- Conversión de tipos  
- Eliminación de caracteres inválidos  
- Corrección de inconsistencias comunes  

### ✔ Detección de errores
Identifica automáticamente:
- Campos vacíos  
- Tipos incorrectos  
- Duplicados  
- Valores fuera de rango  
- Fechas o correos inválidos  

### ✔ Reporte profesional de errores
Genera un archivo `.txt` con:
- Descripción de cada error  
- Cantidad de registros afectados  
- Ejemplos de casos detectados  
- Trazabilidad para auditoría  

### ✔ Visualización del histórico
Produce gráficos que permiten:
- Ver tendencias de errores  
- Identificar patrones  
- Evaluar la calidad del dataset  

### ✔ Archivo depurado listo para análisis
Crea un nuevo Excel/CSV con:
- Datos corregidos o marcados  
- Columna adicional: **error_detectado**  
- Estructura lista para ETL, BI o análisis
